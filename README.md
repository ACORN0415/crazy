# Crazy Arcade (1:1 클론)

Go(WebSocket, 서버 권위 시뮬레이션) + React(Vite) + Three.js(3D 렌더링) 로 만든 크레이지 아케이드 스타일 1:1 대전 게임.

## 실행

```bash
docker compose up -d --build        # http://localhost:8080
WEB_PORT=3000 docker compose up -d  # 포트 변경
```

- `web` 컨테이너(nginx)가 정적 파일을 서빙하고 `/ws` 를 `server:8080` 으로 프록시합니다.
- 로컬 개발: `cd server && go run .` + `cd web && npm i && npm run dev` (Vite가 `/ws` 프록시)

## 기능

- 닉네임 접속, 로비(방 목록 / 접속자 / 채팅)
- 방 만들기(제목, 비밀번호 선택) · 비밀방 입장 시 비밀번호 확인 · 최대 2명
- 마지막 유저가 나가면 방 삭제, 방장이 나가면 방장 위임, 게임 중 이탈 시 상대 기권승
- 방 안에서 **게임 모드 선택**(노멀 / 아이템전 / 맥스), **맵 선택**(빌리지 1 / 해적 14 / 공장 7 / 캠프 1, 미리보기), 준비 → 시작
- 게임: 15×13 맵, 물풍선·연쇄 폭발·블록 파괴·밀 수 있는 블록·풀숲, 물방울 갇힘(5초) → 상대가 닿거나 시간이 지나면 탈락, 제한시간 3분

## 캐릭터

방에서 캐릭터를 고릅니다 (준비 완료 후에는 변경 불가, `랜덤` 가능). 능력치는 `시작/최대` — 원작 캐릭터 소개 이미지의 능력치 막대 기준.

| 캐릭터 | 타입 | 물풍선 | 물줄기 | 속도 |
|---|---|---|---|---|
| 배찌 | 스피드형 | 1/6 | 1/7 | 5/9 |
| 다오 | 밸런스형 | 1/10 | 1/7 | 5/7 |
| 디지니 | 밸런스형 | 2/6 | 1/9 | 4/8 |
| 모스 | 스피드형 | 1/8 | 1/5 | 5/8 |
| 우니 | 파워형 | 1/5 | 2/7 | 5/8 |
| 에띠 | 개수형 | 1/10 | 1/8 | 4/8 |
| 마리드 | 개수형 | 2/9 | 1/6 | 4/8 |
| 케피 | 파워형 | 1/9 | 2/8 | 4/8 |
| 수 | 밸런스형 | 1/8 | 1/7 | 5/8 (원작 자료 없음, 임의) |

수치는 `server/characters.go`. 캐릭터 그림은 원작 인게임 스프라이트(빨간 팀)를 쓰며, 2P는 파란 팀 색으로 자동 변환됩니다.

### 원작 그림 사용

`web/public/characters/<캐릭터>/` 에 PNG를 넣으면 3D 모델 대신 그 그림으로 표시됩니다 (게임·선택창·HUD).
최소 `down.png` 한 장이면 되고, 방향별/걷기 프레임은 `web/public/characters/README.md` 참고.
폴더가 컨테이너에 마운트되어 있어 **다시 빌드 없이 새로고침만** 하면 반영됩니다.

### 원작 그림 (맵·이펙트·아이템)

- `web/public/maps/<테마>/` — 맵 오브젝트·바닥 (`theme.json`). `named`는 맵 `Art` 글자로 고르는 그림(해골 석상, 울타리 등), `decor`는 여러 칸짜리 그림(트럭).
- `web/public/fx/` — 물풍선(3프레임), 물줄기(중심/줄기/끝 + 퍼지는 프레임), 갇힘 물방울, 아이템 아이콘, 탈것(방향별 2프레임).
- 모든 그림은 원작 스프라이트를 AI(Real-ESRGAN)로 4배 고해상도화한 것입니다.
- 해적 14·공장 7·캠프 1은 원작 맵 스크린샷을 칸 단위로 옮겨 적은 배치(미리 깔린 아이템 포함), 빌리지 1은 원작 분위기로 새로 그린 배치입니다.

## 아이템

| 분류 | 아이템 |
|---|---|
| 능력치 | 물풍선(+1), 물약(물줄기 +1), 롤러스케이트(속도 +1), 울트라 물약(물줄기 최대), 빨간 악마(속도 최대) |
| 특수 | 악마(10초 저주: 방향 반전/느려짐/자동 설치/설치 불가), 신발(물풍선 차기) |
| 탈것 | 거북이, 해적 거북이, 부엉이, UFO — 맞으면 대신 내림 |
| 사용(아이템전/맥스) | 바늘(탈출, `1`/`Ctrl`), 방패(3초 무적, `2`), 다트(물풍선 터뜨리기, `3`), 스프링(2칸 점프, `4`) |

수치/드롭 확률은 `server/items.go`, 맵은 `server/maps.go`, 아이콘은 `web/src/itemInfo.ts` 에서 조정합니다.

## 그래픽

- Three.js 3D: 비스듬한 탑뷰 카메라, 캐릭터별 2등신 카툰 모델(걷기·숨쉬기·눈 깜빡임)·탈것, 테마별 벽(마을=집, 해적=술통, 공장=금속), 실시간 그림자
- 게임 화면의 `그래픽` 버튼(또는 `?gfx=low`)으로 저사양 모드(그림자 끔, 해상도 낮춤) 전환
- 렌더링 코드: `web/src/three/` (scene.ts 장면, models.ts 모델, textures.ts 텍스처)

## 조작

`←↑↓→` / `WASD` 이동 · `Space` 물풍선 · `1~4` 아이템 · `Ctrl` 바늘

## 구조

```
server/   Go: hub.go(로비/방 목록) room.go(방·게임 루프 30Hz) game.go(시뮬레이션) items.go maps.go
web/src/  React: App.tsx(화면 전환) components/(Login, Lobby, RoomScreen, GameScreen) three/(3D 렌더링) render.ts(맵 미리보기) net.ts(WS)
```

테스트: `cd server && go test -race ./...`
